# 在输入区直接加入参考图

## 用户故事

- 作为正在写提示词的创作者，我希望把截图或素材直接粘贴到输入区，而不是先找上传按钮再选择文件。
- 作为从文件夹整理素材的人，我希望把图片拖到提示词输入区就能加入参考，而不是必须瞄准很小的参考图按钮。
- 作为已经有参考图的用户，我希望继续粘贴或拖入更多图片时它们追加到当前会话，而不是打断我正在写的提示词。
- 作为收集在线素材的创作者，我希望能显式输入 HTTP/HTTPS 图片链接，把远程图片下载后追加为当前会话参考图。
- 作为在 Canvas 中把图片或结果图接到生成节点继续创作的用户，我希望运行前能看到当前生成节点接收了几张参考图，避免漏连或误连。
- 作为在 Canvas 中一次生成多张图或跑批量变体的用户，我希望每张结果都留在画布上，并且后续都能继续连到生成节点作为参考图。
- 作为已经在工作台准备好当前参考图的创作者，我希望能从参考图缩略图直接加入 Canvas，继续用节点和连线组织创作。

## 为什么需要

参考图是图生图工作流的高频入口，但创作者的素材常常来自截图、剪贴板、文件管理器或已经整理好的工作台参考图。输入区和参考图缩略条都是用户注意力停留很久的位置，如果这里不能直接接住图片并继续进入 Canvas，参考图能力就显得绕了一步。

## 怎么解决

输入区既接收文字，也能识别用户贴入或拖入的图片。文字照常留在提示词里，图片会进入当前会话的参考图列表，并立刻出现在参考图缩略条中。参考图工具区还提供显式链接导入入口，用户输入 HTTP/HTTPS 图片地址后，应用先把远程响应下载为本地参考图载荷，再进入同一导入链路。当前参考图缩略图可以直接加入 Canvas，成为带来源绑定的图片节点；历史图和图库图继续先进入参考图链路再加入 Canvas。Canvas 中连接到生成节点的图片 / 结果节点会被计入生成节点输入摘要，帮助用户在运行前确认参考图上下文；生成出的多张结果会保留为多个 result 节点，每个节点仍可继续作为下游参考图输入。

## 边界

- 只通过显式链接导入入口下载 HTTP/HTTPS 图片；不从 prompt 文本、网页内容或 HTML 片段自动提取远程图片。
- 不把普通文字、HTML 片段或非图片文件转成参考图。
- 不改变已有参考图数量、格式和大小限制。
- 不新增平行素材库；Canvas 只保存参考图、历史图或本地图片的轻量来源绑定和展示源。
